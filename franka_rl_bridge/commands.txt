1. Test basic network functionality
ros2 run franka_rl_bridge test_bc_policy

2. Test with your actual policy (replace with your policy path)
ros2 run franka_rl_bridge test_bc_policy --policy /path/to/your/policy.pt

3. Verify ROS2 topics (make sure Franka is running)
ros2 run franka_rl_bridge verify_topics

4. Monitor observations in real-time
ros2 run franka_rl_bridge monitor_observations

5. Test the actual BC policy runner (with your policy)
ros2 run franka_rl_bridge bc_policy_runner --policy /path/to/your/policy.pt --deterministic

6. In another terminal, start/stop the policy
ros2 topic pub /bc_policy/start std_msgs/msg/Bool 'data: true'
ros2 topic pub /bc_policy/stop std_msgs/msg/Bool 'data: true'
